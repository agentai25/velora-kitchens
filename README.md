# VELORA

Адаптивный сайт вымышленной студии кухонь на заказ. Демонстрационный проект для профессионального портфолио: React, TypeScript, Vite и обычный CSS.

## Запуск

Требуется Node.js 22.12+ (проверено с Node.js 24.19.0) и npm.

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm run build
npm test
```

Сборка сначала выполняет строгую проверку TypeScript. Команда `npm run preview` запускает локальный просмотр готовой сборки.

Браузерные тесты используют Chromium по адресу `/usr/bin/chromium`, если он установлен. Другой путь можно задать через `CHROMIUM_PATH`. Если системного браузера нет, установите его через `npx playwright install chromium`. Тесты автоматически запускают Vite. Они проверяют переключение коллекций, фильтры, диалоги, мобильное меню, FAQ, валидацию и отсутствие отправки/сохранения данных формы, отсутствие горизонтального переполнения на шести размерах экрана. Фотосервис в тестах намеренно недоступен для проверки резервного отображения; тесты не подтверждают доступность внешних фотографий.

## Возможности

- Первый экран, три коллекции, фильтруемая галерея с диалогами, принципы, этапы, FAQ и демоформа.
- Адаптивная вёрстка, мобильная навигация, плавная прокрутка с учётом `prefers-reduced-motion`.
- Управление с клавиатуры, видимый фокус, нативные диалоги с удержанием фокуса и закрытием по Escape.
- Шрифт Golos Text поставляется локально через `@fontsource/golos-text` и включается в сборку.
- Фотографии загружаются с `images.unsplash.com`. Для них нужен интернет; при ошибке показывается нейтральная фирменная заглушка. Изображения используются как интерьерные референсы, а не работы студии. Ссылки централизованы в `src/App.tsx`; для полностью автономного портфолио замените их лицензированными локальными файлами в `public/`.

## Деморежим

VELORA — вымышленная студия. На сайте нет настоящих отзывов, адресов, достижений или коммерческих обещаний. Названия концепций и их площади условны. Форма работает только в браузере: проверяет поля, показывает сообщение и очищает введённое. Сервер, отправка заявок, аналитика и сохранение данных не реализованы. Используйте вымышленные данные.

Никакая публикация или отправка на GitHub не выполняется командами проекта.

## Как открыть сайт и диагностировать предпросмотр

Корневой `index.html` — входной файл Vite, а не автономная HTML-страница. Он подключает `/src/main.tsx`, который требует преобразования TypeScript/JSX и разрешения npm-импортов. Просмотр исходного файла без Vite не запускает React. Даже `dist/index.html` нужно обслуживать вместе с каталогом `dist/assets` по HTTP, а не открывать отдельно.

Для интерактивной проверки на своём компьютере откройте терминал в локальной копии проекта:

```bash
npm ci
npm run dev -- --port 5173 --strictPort
```

Откройте в браузере адрес, который Vite напечатает в терминале. Для проверки production-сборки:

```bash
npm run build
npm run preview -- --port 4173 --strictPort
```

Команды уже используют `--host 0.0.0.0`. Это позволяет обслуживать запросы на сетевых интерфейсах машины, но само по себе не создаёт внешний URL и не настраивает проброс порта. Адрес loopback облачной машины не является адресом вашего компьютера. В текущем интерфейсе облачного онбординга доступный агенту механизм интерактивного веб-предпросмотра/проброса портов отсутствует; открытие `index.html` в просмотрщике файлов его не заменяет.

Диагностика 22.10.2026:

- Статическая выдача исходного HTML без Vite оставляет `#root` пустым: браузер отклоняет TSX-модуль с не-JavaScript MIME-типом.
- Через Vite исходный модуль возвращается как `text/javascript`, страница отвечает HTTP 200 и React рендерит сайт.
- Production-сборка также отвечает HTTP 200 и рендерится без исключений JavaScript.
- Навигация использует якоря (`#collections`, `#projects` и другие), отдельного роутера и серверных маршрутов нет.
- Недоступность Unsplash в облачной среде вызывает сетевую ошибку фотографий; предусмотренная заглушка сохраняет работоспособность страницы.
- Внутренние журналы сообщения «В визуализации произошла ошибка» недоступны агенту. Статический эксперимент подтверждает несовместимость способа открытия с Vite, но не устанавливает точную внутреннюю причину ошибки интерфейса Codex.

Код приложения и конфигурация Vite в ходе этой диагностики не менялись.
